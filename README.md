# OneCatalog Import — 1С-Битрикс

Модуль импорта каталога из [OneCatalog](https://docs.onecatalog.net/) (Wiki API) в
**1С-Битрикс** (инфоблоки `iblock` + торговый каталог `catalog`).

> ⚠️ **Статус: в разработке.** Готового production-релиза пока нет.
> Вся текущая работа — в ветке **[`dev`](https://github.com/OneCatalog/onecatalog-bitrix/tree/dev)**.
> В `main` попадают только подтверждённые production-версии (с тегом `vX.Y.Z`).

- **Стандарт интеграции (канон):** [OneCatalog/onecatalog-standard](https://github.com/OneCatalog/onecatalog-standard)
- **Эталонная реализация:** [OneCatalog/onecatalog-woocommerce](https://github.com/OneCatalog/onecatalog-woocommerce)
- **План порта и ответы:** в ветке `dev` → `docs/`
